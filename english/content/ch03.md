# 第3章 語態

## 觀念入門

### § 1. 語態的種類

語態分主動語態和被動語態兩種：

| 主動語態 | 被動語態 |
| :--- | :--- |
| I **invited** him to the party.<br>（我邀請他參加宴會。） | He **was invited** to the party.<br>（他受邀請參加宴會。） |

### § 2. 被動語態的觀念

(a) 英語裡使用被動語態的場合較多，因此我們要多練習使用。有時候，英語的被動語態句子沒有辦法譯為中文的被動句，因為有觀念上的差別。如例句中的中文，可以看到「被」這個字並沒有出現，但寫成英語時，需從主詞去考慮，若主詞有「被」的意思，則動詞就要用**被動語態**，以 `be + 過去分詞` 表示。

:::example
This book **was written** in 1986.
這本書是 1986 年寫的。
➜ 書是被寫的。

English **is spoken** in America.
在美國是說英語的。
➜ 英語是被說的。

A road **is being built** now.
有一條馬路現在正在修築中。
➜ 馬路被修築。
:::

(b) 在英語中，除了 be 動詞之外，大部分的動詞都在描述動作，因此其前必須有「行為者」，及物動詞則還要有「承受者」。當行為者不知道、不重要或不強調的時候，要用「被動語態」。

:::example
My watch **was stolen**.
我的手錶被偷了。
➜ 是誰偷的，並不重要，或根本就不知道。
:::

### § 3. 主動語態改被動語態的原則

:::formula 基本句型轉換
主動句：主詞 + 及物動詞 + 受詞  
被動句：主詞 + be + p.p. + by + 受詞（受格）
:::

主動語態改為被動語態之步驟如下：

1. 主動句的**受詞**變成被動句的**主詞**。（如為代名詞改為主格）
2. 將主動句的**動詞**改為 `be + p.p.`。被動句的 be 動詞的時態同於及物動詞的時態，be 動詞的人稱、數同於被動句的人稱、數。
3. 主動句的**主詞**，置於 by 之後。（如為代名詞改為受格）

茲以實例說明如下：

:::example
He loves her.
他愛她。
➜ 改為被動：She **is loved** by him.（主動句受詞 her 改為主格 She；loves 改為 is loved；主詞 He 改為 by him。）

Mary wrote two letters.
瑪麗寫了兩封信。
➜ 改為被動：Two letters **were written** by Mary.（注意時態為過去式，新主詞 Two letters 為複數，故 be 動詞用 were。）
:::

### § 4. 被動語態的時態

一般動詞主動語態的時態，共有十二種，但被動語態的時態只有八種：

| 被動句形式＼時間 | 現在 | 過去 | 未來 |
| :--- | :--- | :--- | :--- |
| **簡單式** | 主詞 + am / is / are + p.p. | 主詞 + was / were + p.p. | 主詞 + will / shall be + p.p. |
| **進行式** | 主詞 + am / is / are + being + p.p. | 主詞 + was / were + being + p.p. | （無） |
| **完成式** | 主詞 + has / have + been + p.p. | 主詞 + had + been + p.p. | 主詞 + will / shall have been + p.p. |
| **完成進行式** | （無） | （無） | （無） |

#### 主動語態與被動語態八大時態對照表

| 時態 | 主動：V | 被動：be + p.p. |
| :--- | :--- | :--- |
| **現在簡單式** | He **finishes** it. | It **is finished**. |
| **現在進行式** | He **is finishing** it. | It **is being finished**. |
| **現在完成式** | He **has finished** it. | It **has been finished**. |
| **過去簡單式** | He **finished** it. | It **was finished**. |
| **過去進行式** | He **was finishing** it. | It **was being finished**. |
| **過去完成式** | He **had finished** it. | It **had been finished**. |
| **未來簡單式** | He **will finish** it. | It **will be finished**. |
| **未來完成式** | He **will have finished** it. | It **will have been finished**. |

## 開竅要訣

### 一、被動語態的各種用法

#### 1. 「簡單式」的被動語態

:::formula 簡單式被動形態
- **現在**：am / is / are + p.p.
- **過去**：was / were + p.p.
- **未來**：shall / will + be + p.p.
:::

:::example
Everyone enjoys exciting sports.
人人喜愛令人激動的運動。
➜ 被動：Exciting sports **are enjoyed** by everyone.

They won the game.
他們贏了那場比賽。
➜ 被動：The game **was won** (by them).（那場比賽由他們獲勝。）

They will lose the game.
他們將會輸掉那場比賽。
➜ 被動：The game **will be lost** (by them).
:::

#### 2. 「進行式」的被動語態

:::formula 進行式被動形態
- **現在**：am / is / are + being + p.p.
- **過去**：was / were + being + p.p.
:::

:::example
Miss Li *is teaching* music now.
李小姐現在正在教音樂。
➜ 被動：Music **is being taught** by Miss Li now.

They *were watching* TV when I came.
當我來時他們正在看電視。
➜ 被動：TV **was being watched** by them when I came.
:::

#### 3. 「完成式」的被動語態

:::formula 完成式被動形態
- **現在**：has / have + been + p.p.
- **過去**：had + been + p.p.
- **未來**：shall / will have + been + p.p.
:::

:::example
The building **has been built** for three years.
這棟建築物已經建造了三年了。

The work **had been finished** by six.
這項工作在六點以前就已經做好了。

Before you come back, the building **will have been finished**.
在你回來之前，這棟建築物將已經蓋好了。
:::

#### 4. 「助動詞」的被動語態

主動句中有助動詞時，被動句亦用相同的助動詞。

:::formula 助動詞被動形態
① must + be + p.p. ／ have been + p.p.  
② should / ought to + be + p.p. ／ have been + p.p.  
③ can + be + p.p. ／ have been + p.p.
:::

:::example
Languages **must be learned** in meaningful situations.
語言一定要在有意義的情境下學習。

The house **should be painted**.
這棟房子應該刷油漆。

The dishes **can be washed** in half an hour.
這些碗盤可以在半小時內洗好。
:::

#### 5. 含「感官或使役動詞」的被動語態

:::formula 句型（一）
主詞 + be + seen / heard / felt / made + **to + 原形 V**
:::

:::example
I *saw* him *enter* the room.
我看見他走進這房間。
➜ 被動：He **was seen to enter** the room.

I *made* him *go*.
我叫他走。
➜ 被動：He **was made to go** (by me).
:::

:::note 說明
感官動詞與使役動詞（see, hear, feel, make...）在主動句中其受詞補語用**原形 V**，但在被動句中必須用 **to + 原形 V**。
:::

:::formula 句型（二）
have / get + 物 + p.p.（某物被……）
:::

:::example
He **had** his money **stolen**.
他的錢被偷了。

He **got** his money **stolen**.
他的錢被偷了。
:::

:::tip 活用園地：have / get / make 的受詞補語比較
**(a) have, get 其後的受詞如果是被動時，受詞補語用過去分詞；如果是主動時，受詞補語有不同的變化：**

- `have + 人 + 原形 V`（使某人……）
- `get + 人 + to + V`（使某人……）

**例句：**
- She **had** her brother **help** her.（她叫弟弟幫她。）
- I'll **get** them **to try** it again.（我要叫他們再試一次。）

**(b) make 之後的受詞補語可用過去分詞來說明受詞有被動的含意：**

- 句型：`主詞 + make + 受詞 + p.p.`

**例句：**
- What's making the lake **polluted**?（是什麼東西使湖水受到污染了呢？）
- You must make yourself **respected**.（你必須要讓你自已受到別人的尊敬。）
:::

#### 6. 「S + V + O₁ + O₂」的被動語態

授與動詞（如 give, lend, show, tell, teach, write...）有「直接受詞（D.O.）」與「間接受詞（I.O.）」兩個受詞，可改成兩種被動語態。

:::example
My husband gave me a ring.
我丈夫送我一個戒指。
➜ 以間接受詞 me 改為主詞：I **was given** a ring by my husband.  
➜ 以直接受詞 a ring 改為主詞：A ring **was given (to)** me by my husband.

Mr. Chen teaches us English.
陳先生教我們英語。
➜ 以間接受詞 us 改為主詞：We **are taught** English by Mr. Chen.  
➜ 以直接受詞 English 改為主詞：English **is taught (to)** us by Mr. Chen.
:::

:::tip 活用園地
在「S + V + I.O. + D.O.」的句型中，如果是 write, make, buy 等動詞改被動語態時，以 **D.O.（直接受詞）**當主詞較為自然：

:::example
Mother made me a white dress.
媽媽為我做一件白色的衣服。
➜ A white dress **was made for** me by Mother.（正確）
➜ I was made a white dress by Mother.（不合常理，意為「我被媽媽做成一件白色的衣服」✕）
:::

#### 7. 「S + V + O + C」的被動語態

不完全及物動詞（如 call, elect, choose, appoint...）改為被動語態時，**不可以用補語作主詞，仍要用受詞作主詞**。

:::example
We elected him chairman.
我們選他為主席。
➜ him 為受詞，chairman 為受詞補語。  
➜ 被動：He **was elected** chairman (by us).
:::

#### 8. 「祈使句」的被動語態

:::formula 祈使句被動句型
〔主動〕原形 V + 受詞  
〔被動〕**Let + 受詞 + be + p.p.**
:::

:::example
Do it at once.
立刻做它。
➜ 被動：**Let** it **be done** at once.
:::

#### 9. 「否定句」的被動語態

:::formula 否定句被動句型
〔主動〕主詞 + do / did / does + not + 原形 V + 受詞……  
〔被動〕主詞 + **be + not + p.p.** + by + 受詞
:::

:::note 說明
be 動詞的時態與主動句一致，人稱與新主詞一致。
:::

:::example
He *doesn't teach* English.
他不教英語。
➜ 被動：English **is not taught** by him.

He *didn't study* English.
他沒有研讀英語。
➜ 被動：English **wasn't studied** by him.
:::

#### 10. 「疑問句」的被動語態

##### (a) Yes/No 問句

:::formula 句型（一）：一般動詞
〔主動〕Do / Did / Does + 主詞 + 原形 V + 受詞……？  
〔被動〕**Be + 主詞 + p.p. + by + 受詞……？**
:::

:::note 說明
疑問句之改法，請參考簡單式之原則，然後把 "be 動詞" 調至句首成為疑問句。
:::

:::example
*Did* you *write* the letter?
你寫了這封信嗎？
➜ 被動：**Was** the letter **written** by you?
:::

:::formula 句型（二）：含助動詞
〔主動〕Do 以外的助動詞 + 主詞 + 原形 V + 受詞？  
〔被動〕**助動詞 + 主詞 + be + p.p. + by + 受詞？**
:::

:::example
Can he finish the work in time?
他能及時完成此工作嗎？
➜ 被動：**Can** the work **be finished** in time by him?
:::

##### (b) 特殊疑問句（Wh- 問句）

:::formula 句型（一）：Wh- 當主詞
〔主動〕Wh-（當主詞）+ 動詞 + 受詞……？  
〔被動〕**介系詞 + Wh- + be + 主詞 + p.p. ……？**
:::

:::example
Who wrote the letter?
誰寫這封信？
➜ 被動：**By whom was** the letter **written**?

What surprised you?
什麼東西使你感到驚訝？
➜ 按照主動改被動的原則：You were surprised at what?  
➜ 因本句是疑問句，所以把 be 動詞往前移：**At what were** you **surprised**?（= **What were** you **surprised at**?）
:::

:::formula 句型（二）：Wh- 當受詞
〔主動〕Wh-（當受詞）+ 助 V + S + Vt？  
〔被動〕**Wh- + 助 V + be + p.p. + by + 受詞？**
:::

:::example
What will you do next?
你下一步要做什麼？
➜ 被動：**What will be done** by you next?
:::

:::tip 活用園地：英語寫作中常用被動語態的場合
**(a) 主使者不明：**
- His father **was killed** in the war.（他父親在戰爭中喪生了。）
- English **is spoken** all over the world.（全世界都說英語。）

**(b) 避免主觀或武斷，而用 “It is + p.p.” 的句型：**
- **It is suggested that** we postpone the meeting until tomorrow.（我們建議把會議延到明天。）
- **It is said that** she was a beauty when she was young.（據說她年輕時是個美女。）

**(c) 說話的重點在接受動作動詞，而不在主動者：**
- The man **was hit** by a speeding car.（這個人被一輛超速的車子撞上了。）
- The book **was written** by my mother.（這本書是我母親寫的。）
:::

### 二、被動語態的注意事項

#### 1. 情緒動詞

所謂「情緒動詞」是指可以表達各種「心理感受」（如：“高興”、“滿意”、“驚訝”等）的動詞，如果主詞是「人」的話，通常用「被動式」表達，其句型是：
`人 + be + 情緒動詞的過去分詞` ➜ 表示「某人感到……」。

| 表示高興、滿意 | 表示驚訝 | 其他 |
| :--- | :--- | :--- |
| **amused** | **amazed** | **bored**（厭煩） |
| **delighted** | **astonished** | **tired**（疲倦） |
| **excited** | **startled** | **exhausted**（筋疲力竭） |
| **interested** | **surprised** | **disappointed**（失望） |
| **pleased** | **frightened** | **disgusted**（厭惡） |
| **satisfied** | **shocked** | **convinced**（相信） |

:::example
I am **interested in** English.
我對英語感興趣。

He was **delighted to** meet you.
他很高興見到你。

I was **surprised to** hear the news.
我聽到這消息甚為驚訝。

I am **disappointed in** (或 **with**) her.
我對她很失望。
:::

:::tip 活用園地：有被動形式但無被動意義的片語動詞
下列的片語動詞雖有「被動形式」，但沒有被動的意思：

| 片語 | 中文意義 | 補充說明 |
| :--- | :--- | :--- |
| **be used to + N** | 習慣於 | |
| **be accustomed to + N** | 習慣於 | |
| **be devoted to + N** | 獻身於 | |
| **be dedicated to + N** | 致力於 | |
| **be absorbed in** | 專心於 | |
| **be engaged in** | 從事於 | |
| **be acquainted with** | 熟悉、認識 | |
| **be concerned about** | 關心 | |
| **be opposed to + N** | 反對 | |
| **be supposed to + V** | 應該要 | |
| **be exposed to + N** | 暴露於 | |
| **be well-known for** | 以……著名 | |
| **be made up of** | 由……組成 | = be composed of |
| **be inclined to + V** | 傾向於 | |
| **be wounded** | 受傷 | = be injured = be hurt |
| **be seated** | 就座 | |
| **be located** | 位於 | = be situated |
| **be dressed** | 穿著 | = dress oneself |
:::

#### 2. 不及物動詞 + 介系詞 = 及物動詞

不及物動詞加上介系詞以後，就能有受詞；主動語態如含有「動詞 + 介系詞 + 受詞」的結構時，變為被動語態時，**不要忘記那個介系詞**。

:::example
Mary *laughed at* me.
瑪麗嘲笑我。
➜ 被動：I **was laughed at** by Mary.

She *took care of* the children.
她照顧這些孩子。
➜ 被動：The children **were taken care of** by her.
:::

#### 3. 省略 by

主動語態的主詞為 People, They, You, We, Somebody 等含糊地表示一般人的「人」，變為被動語態時，常將「by + 某人」省略。

:::example
Somebody stole my money.
有人偷了我的錢。
➜ 被動：My money **was stolen** (by somebody).

People speak English in America.
在美國使用英語。
➜ 被動：English **is spoken** in America (by people).
:::

#### 4. 客觀的說法

表示客觀的說明常用 “It is + p.p.” 的句型。下面以常見的 “It is said（據說）” 為例：

:::formula 客觀句型轉換
`People / They say (that) S + V...`  
➜ `It is said that S + V...`  
➜ `S + is / am / are + said to + V（表示現在或未來）／ have + p.p.（表示過去）`
:::

:::example
They say that Mike is sick in bed.
據說麥克臥病在床。
➜ 虛主詞句型：It **is said that** Mike is sick in bed.  
➜ 主詞提前：Mike **is said to be** sick in bed.

People believe that he was killed.
大家相信他被殺了。
➜ 虛主詞句型：It **is believed that** he was killed.  
➜ 主詞提前：He **is believed to have been killed**.
:::

:::tip 活用園地：“It is p.p. + that + 子句” 常見者
- **It is believed that...**（大家相信……）
- **It is expected that...**（大家期待……）
- **It is reported that...**（據報導……）
- **It is said that...**（據說……）
- **It is suggested that...**（有人建議說……）
- **It is thought that...**（大家認為……）
- **It is acknowledged that...**（大家公認……）
:::

#### 5. 下列的動詞或片語動詞不能用被動式

:::warn 注意：無被動語態的動詞與片語
- **take place**（發生）
- **happen**（發生）
- **occur**（發生）
- **belong to**（屬於）
- **break out**（爆發）
- **consist of**（由……組成）
:::

:::example
An accident **happened** here a week ago.
一個星期前在這裡發生了車禍。
➜ 不可說：An accident was happened here a week ago. (✕)

This house **belongs to** me now.
這棟房子現在屬於我。
➜ 不可說：This house is belonged to me now. (✕)
:::

:::tip 活用園地
**(a) “take place” 做「舉行」解時，要注意其用法：**
- We will hold the meeting next Monday.
  = The meeting **will be held** next Monday.
  = The meeting **will take place** next Monday.（下星期一將舉行會議。）

**(b) 「連綴動詞」（如 look, feel, taste, smell, remain 等）沒有被動形式：**
- The coffee **tastes** a little bitter.（這咖啡嚐起來有一點苦。○）
  ➜ 不可說：The coffee is tasted a little bitter. (✕)

**(c) 並非所有及物動詞都有被動形式：**
如：cost（花費）、take（花費）、last（持續）、resemble（像）、have（有）等都沒有被動式。
- The pen **cost** five dollars.（這支筆要五元。○）
  ➜ 不可說：The pen is costed five dollars. (✕)
:::

#### 6. 以「動名詞」或「不定詞」表示被動語態

下列動詞看似主動，但其實含有被動的意義：

1. **be worth + V-ing**（值得……）
2. **need / want / require + V-ing**（需要……）
3. **to let**（出租）、**to blame**（該受責備）

:::example
The book is **worth reading**.
這本書值得一讀。
➜ 等於：The book is **worthy to be read**.  
➜ 等於：The book is **worthy of being read**.

My car **needs checking**.
我的車子需要檢查。
➜ 等於：My car **needs to be checked**.

The house is **to let**.
此屋出租。

You are **to blame**.
你應受責備。
:::

#### 7. 用其他介系詞代替 by

在被動語態中，表示行為者的介系詞，通常用 by；但有些動詞不用 by 而要用其他的介系詞（如 with, at, in, to 等）。

| 介系詞 | 片語動詞（be + 過去分詞） | 中文意義 |
| :--- | :--- | :--- |
| **with** | **be acquainted with** | 認識、熟悉 |
| | **be covered with** | 覆蓋 |
| | **be equipped with** | 裝備 |
| | **be pleased with** | 高興、滿意 |
| | **be satisfied with** | 滿意 |
| | **be crowded with** | 擠滿 |
| | **be filled with** | 裝滿、充滿 |
| **at** | **be amazed at** | 驚訝 |
| | **be astonished at** | 吃驚 |
| | **be startled at** | 吃驚 |
| | **be surprised at** | 驚訝 |
| | **be shocked at** | 震驚 |
| | **be disappointed at** | 失望 |
| | **be frightened at** | 驚嚇 |
| **in** | **be dressed in** | 穿著（衣服） |
| | **be interested in** | 感興趣 |
| | **be absorbed in** | 專心於 |
| | **be engaged in** | 從事於 |
| | **be caught in** | 遇到（風雨等） |
| **to** | **be accustomed to** | 習慣於 |
| | **be used to** | 習慣於 |
| | **be devoted to** | 獻身於 |
| | **be known to** | 為……所知 |
| | **be married to** | 與……結婚 |
| | **be obliged to** | 感激 |
| | **be engaged to** | 與……訂婚 |

:::example
The mountain is **covered with** snow.
山被雪所覆蓋。

He is **pleased with** his new job.
他對新工作很滿意。

I was **surprised at** the news.
這消息使我吃驚。

He is **interested in** music.
他對音樂感興趣。

I am much **obliged to** you for your help.
真謝謝你的幫助。

I was **caught in** a shower on my way home.
我在回家途中遇到陣雨。
:::

:::tip 活用園地：常見介系詞搭配辨析
**(a) 工具 vs 行為者：`with + 工具` ／ `by + 行為者`**
- Bill was killed **by** the man.（比爾被這個人殺死。〔行為者〕）
- Bill was killed **with** a gun.（比爾是被槍打死的。〔工具〕）

**(b) be known 的介系詞搭配：**
- **be known to**（為……所知）：She is known **to** everyone.（她為人人所知。）
- **be known as**（以……身分著名）：He is known **as** a rock singer.（他以搖滾歌手而著名。）
- **be known by**（藉著……而知）：A man is known **by** the company he keeps.（觀其友而知其人。）

**(c) be made 的介系詞搭配：**
- **成品 + be made of + 原料**（物理變化，看得出原料／不變質）：The table is made **of** wood.（這張桌子是木製的。）
- **成品 + be made from + 原料**（化學變化，看不出原料／變質）：Wine is made **from** grapes.（葡萄酒是由葡萄做成。）
- **原料 + be made into + 成品**：Grapes are made **into** wine.（葡萄被做成葡萄酒。）
:::
